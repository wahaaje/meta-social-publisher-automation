# Sample media layout

The sample queue expects this structure inside the configured Google Drive root folder:

```text
Campaign_Media/
├── 02_Single_Image_Posts/
│   └── DEMO-001.jpg
├── 03_Carousels/
│   └── DEMO-002/
│       ├── DEMO-002-01.jpg
│       ├── DEMO-002-02.jpg
│       └── DEMO-002-03.jpg
└── 04_Reels/
    └── DEMO-003/
        └── DEMO-003.mp4
```

No media is included in this repository. Add files you own or are licensed to publish, keep capitalization identical, and do not reuse the same relative path for different assets.
